# 🚀 Google Developer Groups (GDG) - Machine Learning Workshop

Welcome to the **GDG Machine Learning Workshop** repository! This repository is designed specifically for **beginners, students, and freshers** to learn practical Machine Learning in Python without getting overwhelmed.

Each model lives in its own dedicated folder with:
- 📓 The complete Jupyter Notebook (`.ipynb`).
- 📖 A beginner-friendly, cell-by-cell copy-paste guide (`README.md`) ready to run in Google Colab.
- 💡 Simple real-world analogies explaining what every step does and why we do it.

## 🎓 How to Get Started (For Students & Freshers)

1. **Pick a module above** (e.g., [Social Network Ads](./social_network_ads/) or [Titanic Survival](./titanic_survival/)).
2. Open [Google Colab](https://colab.research.google.com/).
3. Open the module's `README.md` and follow the numbered steps in order:
   - **Step 1:** Copy code into a cell $\rightarrow$ Press `Shift + Enter`.
   - **Step 2:** Repeat for each step in order without skipping.
4. All datasets are fetched directly from public URLs, so no local file download or upload is needed!
